## How this repo is built

The exercises follow the freeCodeCamp curriculum: the base requirements come from the platform's workshops and labs. What I add is the presentation layer: a custom interface for each project and a live demo, so a visitor can see the result working. Each page states its origin in the footer.

React pages load React 18 from a CDN. Projects 04 and 05 are written in TypeScript (`index.ts` / `index.tsx`) and compiled to `script.js`.

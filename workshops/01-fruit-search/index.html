React · useState · useEffect · debounce

FruitFinder

Type a fruit name. The search runs 700 ms after you stop typing, and the effect cleans up its timer on every keystroke.

Based on the freeCodeCamp "Build a Fruit Search App" workshop (Front-End Development Libraries v9). The debounced useEffect follows the platform's workshop (it queries the freeCodeCamp fruit API); the interface and the local fallback list were designed for this page.
